# 船・車の注釈データ

空中写真の船・車を数える検出モデルを、自前で学習するための注釈です。
既製のモデル（DOTA 由来・AGPL の重み）は使わない方針なので、正解もここで一から作ります。

- **注釈：CC BY 4.0**（sat_ai_vision）。使うときは出典として、このリポジトリと下の写真の出典を示してください。
- **写真：国土地理院「全国最新写真（シームレス）」**（公共データ利用規約 PDL1.0）。画像はここに入れず、
  タイル座標から取り直します。学習に使う画像は「国土地理院『全国最新写真（シームレス）』を加工して作成」と示します。

## 中身

| ファイル | 中身 |
| --- | --- |
| `sites.json` | 地点（名前・中心の経緯度・主にどちらを付けるか）。1 地点は中心から 3×3 チップ（約 750 m 四方） |
| `chips/18-<x>-<y>.json` | 1 チップの注釈。z18 のタイル 2×2（512 px 四方、約 0.5 m/px）。x, y は左上のタイル |

注釈の座標は、チップの左上を原点とする画素（z18 基準、右と下が正）です。

```jsonc
{
  "id": "18-232888-103050", "z": 18, "x": 232888, "y": 103050,
  "site": "laketown", "mpp": 0.484,
  "reviewed": { "ship": true, "car": false },   // 種類ごとに、人が確かめ終えたか
  "updatedAt": "2026-10-30T09:00:00.000Z",     // 書き換えたら必ず新しくする（下の「書き換えるとき」）
  "objects": [
    // 車：中心の点
    { "id": "h-…", "kind": "car", "status": "accepted", "source": "human", "x": 101.5, "y": 220 },
    // 船：回転した矩形。angle は長辺の向き（ラジアン、右向きから時計回り、-π/2〜π/2）
    { "id": "auto-…", "kind": "ship", "status": "accepted", "source": "auto",
      "cx": 300, "cy": 180, "length": 60, "width": 14, "angle": 0.42, "difficult": true }
  ]
}
```

- `status`：`proposed`（候補。まだ人が確かめていない）／`accepted`（人が確かめた）
- `source`：`auto`（土地被覆と明るさからの自動の候補）／`claude`（Claude の下付け）／`human`（人が付けた）
- `difficult`：隠れている・見分けにくい。学習では正解にも誤りにも数えない

**学習に使うのは、その種類が `reviewed` のチップだけ**です。確認済みのチップでは、付いていない所に
船（車）は無いものとして扱います。

### 書き換えるとき

注釈ページは、開いたときの `updatedAt` を付けて保存し、その後にほかの所で書き換わっていたら上書きせずに止めます。
ファイルを直接（手やスクリプト、Claude の下付けで）書き換えるときは、**`updatedAt` を必ず現在時刻にする**か、
`PUT /api/dev/annotate/<id>`（`{ objects, reviewed, updatedAt }`）で書いてください。`updatedAt` が同じままだと、
注釈ページで開いたままの古い内容で上書きされます。JSON が壊れたファイルは、注釈ページも `annotate:prepare` も上書きせずに知らせます。

## 注釈の決まり

**車**（中心に 1 点）

- 乗用車・軽・トラック・バス・トレーラーの頭。停まっている車も走っている車も付ける。
- 屋根・高架・木の下で見えないものは付けない。半分ほど見えるものは付けて `difficult` にする。
- 立体駐車場の屋上の車は付ける。チップの縁で切れた車は、中心がチップの中にあれば付ける。

**船**（船体に合わせた回転矩形）

- 漁船・客船・貨物船・ヨット・プレジャーボート・屋形船。水上でも、陸に揚げてあっても付ける。
- 並んで係留された船も 1 隻ずつ。重なって境目が見えないものは `difficult`。
- 浮き桟橋・ブイ・いかだ・養殖の施設は付けない。チップの縁で切れた船は、見えている部分に合わせる。

## 作り方

```bash
npm run dev
BASE_URL=http://localhost:3000 npm run annotate:prepare            # sites.json の全地点のチップと候補を作る（あるチップは触らない）
REDO=1 BASE_URL=http://localhost:3000 npm run annotate:prepare     # 人が手を付けていない種類だけ、自動の候補を出し直す
open http://localhost:3000/dev/annotate                             # 注釈ページ（next dev でだけ開ける）
BASE_URL=http://localhost:3000 npm run annotate:smoke              # 注釈ページの動作確認（データは変えない）
```

自動の候補は学習したモデルではなく、土地被覆（FLAIR）と明るさだけで出したものです（`lib/server/annotate/candidates.ts`）。
取りこぼしが多い（並んだヨット、岸壁に着けた大型船、暗い色の車）ので、消すだけでなく足す前提で見てください。
